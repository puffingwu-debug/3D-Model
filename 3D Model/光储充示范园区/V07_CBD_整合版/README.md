## 下载说明

- `光储充示范园区_V07_CBD整合.zip`：完整工程包，包含 Blender 工程、Web 场景、脚本、贴图、字幕和检查记录。
- `pv_park_500mu_v07.blend`：可直接使用 Blender 打开的园区主文件。
- `park.glb`：Draco 压缩的 Web 场景。
